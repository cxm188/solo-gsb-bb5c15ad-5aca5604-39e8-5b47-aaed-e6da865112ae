# 路由歧义排查器

粘贴 API 网关路由规则（静态段、`:param` 单段参数、`*` 多段通配、优先级），
自动找出可能同时命中的规则对，生成最短具体冲突见证路径，并按
「优先级数字越大越先，平手按输入顺序」模拟最终命中；支持禁用单条规则即时重算、导出冲突 JSON。

## 启动

```bash
docker compose up --build
```

## 访问

- 地址：http://localhost:8080
- 端口：宿主机 `8080`（在 `docker-compose.yml` 的 `ports` 中调整）；容器内端口由环境变量 `PORT` 控制，默认 `8080`

## 规则格式

每行一条：`<优先级> <路径模式>`，`#` 开头为注释，优先级可省略（默认 0）。示例：

```
10 /api/users/:id
20 /api/users/new
5  /api/*
```
